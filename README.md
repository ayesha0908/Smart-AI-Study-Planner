# Smart AI Study Planner with Personalized Scheduling

## Project Overview

This project is designed to generate personalized study schedules using rule-based decision making and adaptive prioritization techniques.

The planner analyzes multiple factors including:

- Subject difficulty
- Student proficiency level
- Exam proximity
- Available study hours

Based on these inputs, the system dynamically creates a study strategy and schedule.

---

## Features

- Personalized study hour allocation
- Difficulty and strength analysis
- Exam-date priority adjustment
- Dynamic 7-day study schedule
- Theory / Practice / Revision distribution
- Priority explanation system
- Pie chart visualization
- Bar chart visualization
- Study schedule table generation
